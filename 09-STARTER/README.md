# Next.js creative starter

## Baseline
- Next.js App Router
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Motion

## Optional by need
- Lenis: smooth scrolling
- OGL: lightweight WebGL/shaders
- three + @react-three/fiber + @react-three/drei: real 3D
- Theatre.js: art-directed timeline sequences

## Production rules
- Keep server/client boundaries deliberate.
- Dynamically load expensive visual modules.
- Never block LCP on WebGL.
- Use responsive poster/video sources.
- Test touch, reduced motion, low-power devices and Safari.
- Run visual verification at desktop and mobile breakpoints before merge.
