# Creative reference sources

- Codrops / Tympanus: experimental web techniques, shaders, WebGL and interaction studies.
- Awwwards: useful for composition/motion references; never copy a site's identity.
- Upstream library examples: best source for supported APIs.
- Context7: use for current implementation documentation when coding.

Capture the *principle* behind an inspiration (camera behavior, typography rhythm, transition logic), not its branded expression.
