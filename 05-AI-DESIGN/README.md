# AI / visual design workflow

1. Research/reference gathering.
2. Explore several distinct art directions in MagicPath or Figma.
3. Lock typography, composition, spacing and interaction intent.
4. Use pen.dev when a code-adjacent design canvas materially improves iteration.
5. Implement in Next.js; do not export a pile of opaque generated code.
6. Use Context7/current docs for library APIs.
7. Verify in-browser on mobile and desktop.
