# Recipe index

## Hero / storytelling
- cinematic-video-hero — full-bleed video, art-directed overlays, GSAP entrance and scroll handoff
- industrial-fluid-shader — OGL distortion/refraction treatment with mobile fallback
- product-reveal — staged product/model reveal; CSS/video first, R3F when true 3D is justified
- scroll-storytelling — pinned chapters, controlled pacing, accessibility escape hatch

## Interface
- premium-navigation — desktop + purpose-built mobile nav choreography
- magnetic-cta — restrained pointer response, disabled on touch/reduced motion
- technical-data-overlay — engineering/CAD-inspired information layer without visual clutter

## Performance
- mobile-fallback — capability-aware reduction of canvas/video/filter cost
- reduced-motion — equivalent static composition for accessibility

Each recipe should eventually contain: goal, when to use, when not to use, dependencies, implementation, mobile behavior, reduced-motion behavior, and performance budget.
